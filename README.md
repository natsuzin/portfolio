# Portfólio

Meu portfólio pessoal em português e inglês.

🔗 [natsuzin.github.io/portfolio](https://natsuzin.github.io/portfolio/)

## Como rodar

Requer Node.js 20.19+.

```bash
npm install
npm start        # http://localhost:3000
npm run build    # versão de produção em dist/
```

## Onde editar

- **Conteúdo:** `src/app/core/data/content.pt.ts` e `content.en.ts`
- **Imagens e currículo:** `public/images/` e `public/curriculo/`
- **Cores e fontes:** `src/styles.scss`

## Tecnologias

Angular 20, TypeScript, SCSS e deploy automático no GitHub Pages via GitHub Actions.
